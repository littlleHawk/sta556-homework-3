X and y must have compatible shapes because one row of parameters in X represents one observation, corresponding to one response in each row of y. The intercept column is included as all 1s to apply an equal \(\beta_0\) parameter to each value and to represent the baseline value when all predictor values are zero. This dataset has values in precip_mm that are generally 20 times higher than those of mean_temp_c. Standardizing the predictors places all their values on a common scale of deviation from the mean, so they have similarly scaled parameters and the regression is more consistant. Numpy broadcasting allows operations on arrays of compatible shapes and performs these operations element-by-element by vectorizing the equation.

3.2 Calculate fitted values and residuals

fitted = X @ beta_hat
residuals = y - fitted
rmse = np.sqrt(
np.mean(
residuals ** 2))
print(f"Residuals mean: {residuals.mean()}\n")
print(f"RMSE: {round(rmse, 4)}")
Residuals mean: -4.121147867408581e-15

RMSE: 7.5135

X @ beta_hat is the matrix multiplication \(X\hat{\vec{\beta}}\) which results in the vector of predicted values \(\hat{\vec{y}}\) created using the linear model. The residual mean is nearly zero, indicating the model is finding the best fit line between all given predictor values such that their distances from the line (\((y_i -\hat(y_i))^2\)) cancel each other out: the model does not over or under predict any particular values. RMSE summarizes the typical distance of a residual point from the mean zero, or the average magnitude of error. This value matches the standard deviation of residuals. In these calculations, we use X @ beta_hat instead of X * beta_hat because the former is standard matrix multiplication and the latter is an element-wise matrix multiplication that applies beta_hat down each column and does not sum any values.

Q @ R \(\approx\) X verifies that Q and R are the factored decomposition of X into orthogonal and upper triangular matricies, Q and R. Q.T @ Q \(\approx\) I verifies Q is indeed orthogonal. The singular values \(\sigma\) of the SVD show the directions in which the linear model is most and least drawn towards and therefore most and least represented in the model.

A large condition number suggests the predictors are sensitive to small changes and that the predictors are nearly linearly dependent. After standardization, the condition number decreased from {python}round(raw_cond, 3) to {python}round(np.linalg.cond(X), 3).
